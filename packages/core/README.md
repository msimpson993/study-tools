# @study/core

Shared UI and math for the study pages: theme, page shell, concept map, figures, controls, quiz, and `@study/core/dsp` (complex, FFT/DFT/DTFT, windows, interpolation droop, LTI/state-space helpers, transfer functions `tf` and the PID loop simulator `pid`; see `docs/dsp-control.md`). See `docs/components.md` at the repo root. Tests: `npm test` (`test/dsp.test.ts`, `test/tf.test.ts`, `test/pid.test.ts`, `test/maplayout.test.ts`).
