# transforms

Six domains of linear systems (CT, DT, CF, DF, S, Z). A question map (`content/graph.yaml`) leads into the original board (`src/board/`, migrated 1:1): nine transform arrows with forward and inverse pair views, draggable poles, 20 examples in 5 tabs, 9 windows, ZOH/FOH/sinc. `src/model.ts` is the unit-tested signal model (Laplace/Fourier/Z/DTFT agreement). Deep link: `#/board?pair=<ft|lap|zt|dtft|dft|fs|samp|fsamp|map>&preset=<example id>`.
