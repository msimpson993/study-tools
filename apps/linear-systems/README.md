# linear-systems

Linear Systems Analysis: what a linear system is, and how to predict what it does to any input. Two question maps (Big picture 15 boxes / 15 lines, Full detail 34 boxes / 39 lines), 30 deep dives, 27 live figures drawn on two running examples (an earbud speaker and a two-room house), 93 self-check questions, 4 review pages and a 95-term glossary. Optimal control and feedback appear as applications. Content in `content/`, figures in `src/figs/` (`ex.ts` holds the tested models). Guard: `expect:` in `subject.yaml`.
